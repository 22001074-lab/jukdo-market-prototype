죽도시장 가격비교 프로토타입

관광객이 죽도시장에서 합리적인 가격에 물건을 살 수 있도록, 상인의 실시간 가격 등록과 손님의 리뷰로 신뢰를 쌓는 가격비교 서비스를 기획부터 35회 이상의 반복 개발까지 끌고 온 기록입니다.

문제 — 왜 시작했나

"20대 관광객 배예령씨는 시장에 갈 때 상품들의 가격을 제대로 알지 못하는 상태로 가는 것이 불편하다."

전통시장에서는 같은 품목이라도 매대마다 가격이 다르고, 관광객이 그 자리에서 "이 가격이 정상인가?"를 확인할 방법이 없습니다. 이 프로토타입은 이 한 문장의 불편에서 출발했습니다.

과정 — 어떻게 만들었나

"시장 상인과 구매자가 상품에 대해 가격을 입력할 수 있다. 이를 통해 시장의 상품 가격을 알 수 있다."

이 구조를 실제로 작동하게 만들기 위해, 세 명의 이해관계자를 동시에 만족시키는 방식으로 설계했습니다 — 손님은 검색 한 번으로 매장별 가격을 비교하고, 상인은 오픈채팅방으로 받은 당일 인증 PIN으로 본인 가격을 직접 등록하며, 다른 손님들은 영수증 인증 후 남긴 리뷰로 그 가격이 실제로 맞는지 서로 검증합니다.

AI 활용 — 맡긴 것과 검증한 것

웹사이트의 기초적인 뼈대는 AI(Claude)에게 요청 사항을 구체적으로 지시해 생성하게 했습니다. 대신 그 결과를 그대로 쓰지 않고, 직접 화면을 클릭하며 실사용 테스트를 거쳐 검증했습니다 — 지도 오검색, 모달 텍스트 겹침, 찜한 목록 탭 혼동, 매장 중복 생성 위험 같은 문제들은 코드를 눈으로 훑어서가 아니라 실제로 눌러보고 스크린샷을 확인하며 찾아낸 것들입니다. AI가 짠 코드를 검수 없이 배포하지 않고, "정말 저 흐름대로 동작하는가"를 팀이 직접 확인하는 과정을 반복했습니다.

팀 협업 — 6강 고도화 우선순위표

"기준 없이 고치면 색상만 종일 만집니다. 필수부터 처리합니다." — 팀이 정한 원칙대로, 개선 항목을 필수/사용성/나중으로 나누고 담당을 명확히 나눠 처리했습니다.

필수

kg당 가격 표시로 전환

단순 총액 대신 kg당 단가로 바꿔 실제 시세 비교가 가능하게 함 — 담당 한대성

필수

"폰 속의 폰" 어색함 수정

실제 모바일 브라우저에서 폰 목업 틀 없이 화면 전체를 꽉 채우도록 개선 — 담당 배예령

사용성

택배 가능 여부 표시

매장별 택배 가능 여부를 필터·상세 정보에 노출 — 담당 마수현

사용성

리뷰 버튼 중복 클릭 방지

"가격 맞아요/달라요" 버튼의 중복 투표를 막아 데이터 신뢰도를 지킴 — 담당 김민성

사용성

4개 언어 지원

한국어·영어·중국어·일본어 UI를 추가해 외국인 관광객 접근성을 높임 — 담당 준호

기본 기능

탐색

카테고리 · 오타 허용 검색

해산물·과일·나물·목공예 등 큰 카테고리로 먼저 둘러보고, 오타나 유사어("낙지"→"문어")로 검색해도 원하는 품목을 찾아줍니다.

비교

가격 목록 · 필터 · 정렬

가격대·신선도·손질 정도·원산지 필터와 4가지 정렬 기준으로 매장별 가격을 비교하고, 평균 대비 위치·이상치 경고·전일 대비 변동을 배지로 바로 확인합니다.

신뢰

PIN 인증 상인 가격 등록

상인 전용 오픈채팅방에서 매일 공지되는 4자리 PIN으로 본인 인증 후, 본인 가게의 품목별·수량별 가격을 표 형태로 한 번에 관리합니다.

신뢰

영수증 인증 리뷰

실제 구매를 확인한 손님만 "가격 맞았어요 / 달라요"를 남길 수 있게 해, 아무나 남기는 리뷰보다 신뢰도 높은 데이터를 쌓습니다.

편의

찜하기 · 동선 안내

마음에 든 가격을 찜해두고, 구역 번호 순서로 정렬해 찜한 가게를 도는 동선을 짧게 만들 수 있습니다.

접근성

다국어 · 지도 · 터치 타겟

4개 언어 UI, 실제 시장 위치 지도·길찾기 링크, 그리고 표준 최소 터치 타겟(44px) 기준에 맞춘 버튼 크기로 접근성을 다졌습니다.

v35 — 4가지 관점 시뮬레이션이 낳은 혁신 기능

"손님이라면", "상인이라면", "외국인 관광객이라면", "시장 전체를 운영한다면" — 네 가지 입장에서 각각 무엇이 아쉬울지를 시뮬레이션해 12개 기능으로 구체화했습니다.

손님 관점

목표가 알리미

품목에 "이 가격 이하면 알려줘" 기준을 걸어두면, 조건을 만족하는 매장이 나타났을 때 배너로 바로 알려줍니다.

손님 관점

장보기 최적 플랜

찜한 품목들을 각각 지금 제일 싼 매장 기준으로 묶어, 매장별 소계와 전체 예상 총액을 한 번에 보여줍니다.

손님 관점

나의 시장 요약

좋아요·비교함·동선 완주 체크·예상 총액을 한 카드로 모아 정리하고, 텍스트로 복사해 공유할 수 있습니다.

외국 관광객

문구집 음성 재생

"이 가격 맞아요?" 같은 한국어 문장을 눌러서 들어보고, 상인에게 화면을 보여주며 소통할 수 있습니다.

외국 관광객

4개 언어 · 다중 통화 환산

언어를 일본어·중국어로 바꾸면 그에 맞는 통화 환산까지 함께 보여주도록 확장했습니다.

상인 관점

내 가게 성과 요약판

가격 관리 표를 열자마자 우리 가게의 리뷰 신뢰도와 최근 손님 후기를 요약해서 보여줍니다.

상인 관점

실시간 가격 입력 힌트

가격을 입력하는 그 자리에서, 타이핑하는 순간 바로 다른 매장 시세 대비 위치(낮음/비슷/높음) 배지를 보여줍니다.

시장 전체

실시간 소식 · 오늘의 특가 · 신뢰 랭킹

시장 전체 관점의 새 화면 3종을 탭 하나로 묶어, 시장 전체의 오늘 상황을 한눈에 보여줍니다.

개발 타임라인

V1
시작 화면 프로토타입
한 줄 소개 + 검색창 + CTA 버튼만 있는 정적 시작 화면에서 출발. 흰 배경에 포인트 컬러 하나만 쓰는 원칙을 세움.
V2–V10
골격 구성 + PIN 인증 + 리뷰 신뢰 구조
정렬·검색·가격 목록으로 기본 골격을 잡은 뒤, PRD로 먼저 정의한 상인 PIN 인증 가격 등록과 손님 리뷰를 구현. QR 스캔 대신 오픈채팅방 PIN 방식으로 방향을 전환.
V11–V15
신뢰도 강화 + 실사용 방지책
평균가 대비 배지, 실물 사진 첨부가 추가되고, 이름을 줄여 쳐도 중복 가게가 실수로 생기지 않도록 확인 단계를 추가함.
V17–V20
접근성 개선 1차 + 가격 변동 인사이트
터치 타겟을 표준 44px 기준으로 키우고, 이상치 경고 칩·전일 대비 변동 칩·가격 추이 스파크라인·동선(길찾기) 모달을 도입.
V22–V27
다국어 확장 + 관점별 코드 리뷰
4개 언어 지원과 지도 연동을 마친 뒤, "손님 관점", "상인 관점", "외국 관광객 관점" 리뷰를 각각 돌며 버그와 접근성 문제를 체계적으로 찾아 수정.
V29–V32
공유 버전 도입 + 시장 전체 관점 신설
읽기 전용 공유 상태 배너를 만들어 다른 사람과 안전하게 공유할 수 있게 하고, 실시간 소식·오늘의 특가·신뢰 랭킹을 묶은 "시장 전체" 관점 화면을 새로 만듦.
V33–V34
동선 시각화 + 매장 비교함
찜한 가게를 잇는 동선을 실제 매대 배치를 반영한 지도 그래픽으로 보여주고, 매장을 최대 3개까지 담아 표로 나란히 비교하는 기능을 추가.
V35
4가지 관점 시뮬레이션 · 공유 배포
3000회 시뮬레이션 기반으로 손님·상인·외국 관광객·시장 전체 관점의 혁신 기능 12종을 완성하고, GitHub Pages로 공개 배포.

결과 — 무엇이 남았나

"일반 사용자들은 자신이 관심있는 물품을 검색하고 가장 최신의 가격을 알 수 있다. 시장 상인들은 상인들에게만 공유된 비밀번호로 자신의 상품의 가격 및 상품 구성을 수정하여 올릴 수 있다."

이 목표는 v35 시점에 단순 검색·등록을 넘어, 목표가 알리미·장보기 최적 플랜·실시간 가격 힌트 같은 기능으로 확장되어 구현되어 있습니다.

남은 한계 · 다음 단계

"비밀번호로만 상품 추가·삭제·수정 등을 할 수 있는 화면에 들어가는 기능이며, 실제 상인들이 협조하여 상품의 가격을 업로드 할지 의문이다." — 팀이 스스로 짚은 한계입니다. 여기에 직접 써보며 찾은 사항을 더했습니다.

우선

실제 상인 참여 유도가 검증되지 않음

PIN 인증 구조는 완성됐지만, 실제 상인들이 매일 가격을 직접 입력해줄지는 아직 실증되지 않은 가정임.

우선

찜한 목록 기본 탭 혼동

가격을 찜하면 배지엔 바로 반영되지만, 목록을 열면 기본 탭("찜한 가게")이 비어 보여 찜이 안 된 것처럼 오해할 수 있음.

낮음

환율 환산 고정값 · 백엔드 미연동

원화→환율 환산이 2026년 8월 기준 고정값이고, PIN·리뷰·가격 데이터는 새로고침 시 초기화되는 세션 메모리 상태 — 실서비스 전환에는 환율 API와 백엔드 연동이 필요함.

낮음

지도 서비스 전환 검토

현재 Google Maps iframe을 사용 중이며, 카카오맵으로 바꾸려면 Kakao Developers에서 발급받은 JavaScript 앱 키가 필요함.
