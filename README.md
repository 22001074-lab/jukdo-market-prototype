# 죽도시장 가격비교 프로토타입

물품을 검색하면 죽도시장 내 매장별 가격을 비교하고, 상인은 PIN 인증 후 직접 가격을 등록하며, 손님은 리뷰(가격 정확도)를 남길 수 있는 모바일 웹앱 프로토타입입니다. 4가지 이해관계자 관점(손님·상인·외국 관광객·시장 전체) 시뮬레이션 기반 혁신 기능까지 35회 이상 반복 개발되었습니다.

- **라이브 데모**: https://22001074-lab.github.io/jukdo-market-prototype/
- **케이스 스터디**: https://22001074-lab.github.io/jukdo-market-prototype/case-study.html

## 핵심 기능
- 카테고리 탐색 + 오타 허용 검색
- 가격대·신선도·손질 정도·원산지 필터, 평균가 대비 배지, 전일 대비 변동
- PIN 인증 기반 상인 가격 등록 (품목별·수량별 가격표 관리)
- 영수증 인증 후 남기는 "가격 맞았어요/달라요" 리뷰
- 찜하기 + 구역 기반 동선 안내
- 4개 언어(한·영·중·일) 지원, 시장 위치 지도 연동
- v35: 목표가 알리미, 장보기 최적 플랜, 나의 시장 요약, 문구집 음성 재생, 매장 성과 요약판 등 관점별 혁신 기능

## 기술 스택
백엔드 없이 단일 HTML 파일(인라인 CSS·JS)로 만든 정적 프로토타입입니다. HTML5, CSS3, Vanilla JS, Web Speech API, Google Maps Embed, GitHub Pages로 배포되었습니다.

## 알려진 한계
- 찜한 목록 화면의 기본 탭과 실제 찜하기 동작(품목 단위) 불일치로 혼동 가능
- 실제 상인들이 협조하여 매일 가격을 직접 입력해줄지는 아직 검증되지 않은 가정
- 환율 환산이 특정 시점 기준 고정값으로 하드코딩됨 — 실서비스 전환 시 API 연동 필요
- 지도는 현재 Google Maps iframe 사용 중이며, PIN·리뷰·가격 데이터는 새로고침 시 초기화되는 세션 메모리 상태

이 프로젝트는 예시 데이터를 사용한 학습·기획용 프로토타입입니다.
